# Landing Page

A simple landing page project built with HTML and CSS.

## Project Structure

- `landing page.html` - Main HTML file for the landing page.
- `landing page.css` - Stylesheet used by the landing page.
- `data/` - Contains assets used by the page, including `superman-2025-official-poster-1.avif`.

## Usage

1. Open `landing page.html` in a web browser.
2. Make edits to `landing page.css` to change styling.

## Notes

- This is a static front-end project with no build tools or dependencies.
- Use the `data` folder for image and media assets.
